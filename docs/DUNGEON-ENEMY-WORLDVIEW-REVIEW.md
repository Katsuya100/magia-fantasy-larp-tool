# ダンジョン敵217体：確定世界観ルールの魔法整合レビュー（PR #167）

> 通しプレイ・勝率評価は別セッション。これは静的な属性・魔法役割レビューです。

## 適用した世界観ルール

1. 名前が明示する炎・雷・水（氷）・風などの属性を主属性にする。
2. 普通の動物・亜人は魔法というより攻撃性質の表現。飛行は風、水棲は水、物理打撃・地上戦は重力が使える。ダンジョンの魔力を使う個体もあり得るが、単なる動物に根拠のない炎・雷を割り当てない。
3. 毒・呪い・腐敗は混沌を基本とし、水や霧などの環境は副属性にする。
4. 死霊・骸骨・吸血鬼の主属性を一律に混沌としない。生前の武具や由来が読める場合にはそれを主属性にして、混沌を副属性に残せる。回復役割の魔法はアンデッドでは防御魔法に置換する。
5. 石・鉄・重量・ゴーレムは重力。魔法制御は秩序、電気機構は雷。
6. 善悪と秩序・混沌は別。悪の騎士や堕天使でも秩序の魔法を使える。
7. 因果と予言は秩序、天体と重量は重力、幻影と虚無は混沌。

**未解決の扱い:** 2体は名前だけで安全に属性を確定できないため据置。専門職の流派、魔獣固有能力、精霊の系譜、古神の神格など個別設定が必要。自動で混沌へ寄せたり、種族だけで属性を決定したりしない。

## 先行修正45体とアンデッド補正

先行45体の属性は `scripts/dungeon-enemy-spell-flavor.mjs` の全IDを明示した差分で再生成可能。死霊が混沌一色になることを防ぐため、屍術士など直接混沌魔法を使う術師と、剣・鎧・霧・飛行に由来する死霊を分けた。アンデッドの回復は名前からの判定に基づくため、霊的な場所の住人というだけではアンデッド扱いしない。

## テスト範囲

`tests/test-dungeon-enemy-worldview.mjs` は500体の不変項目、元データからの再生成、217体の扱い、既存45体、アンデッドの非回復、役割・威力の不変を検証。通しプレイは含めない。
