# ダンジョン：デバフ使いのフレーバー配置（20〜100層）

各層5体のうち、名前・属性・種族・立場を見て**2体だけをデバフ使い**として残す。単純な固定スロット割り振りではなく、呪術師・精霊・死霊・魔眼・毒生物・術を操るボスを優先する。残り3体のデバフ枠は、同じ属性・同じ威力の防御魔法に差し替える。

戦闘ではデバフ使いだけが利用可能時に**24%の確率でデバフを優先**し、それ以外は従来の行動抽選へ戻る。回復優先AIは変更しない。1〜19層は非デバフ戦として完全維持。20〜100層は各10層区間で、旧データを使った128シードのデバフ使用回数と影響を受けた戦闘の割合を下回らないことをCIで検証。

## 属性・威力・対策アイテム
- 20〜50層のデバフ威力は旧値を維持。**51〜100層はPR #161の漸増威力**：51層の最低250、100層の最低750・最大780。人数配分変更後も各層2体の最低・最高威力を固定。
- デバフ解除アイテムの性能・入手率、通常攻撃魔法、HP/MP等はこの配置変更では触らない。
- 構成・実際の発生頻度は `tests/test-dungeon-debuff-role-distribution.mjs`、対策装備あり/なしの実戦闘は `tests/test-dungeon-deep-cleanse-simulation.mjs` を参照。
