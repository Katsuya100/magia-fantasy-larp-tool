# 全500体の耐久・属性フレーバー点検（PR #167）

## このPRで実施したこと

全通常敵400体・ボス100体を役割別に分類し、HP・物理防御(DEF)・魔法抵抗(RES)を名前から想像できる範囲へ調整。見た目の説明が曖昧な敵は、根拠なく高耐久化しない。属性耐性も別途、名前に示された属性と矛盾しないようにする。

**MAGと魔法陣全5枠（属性・威力・役割）、敵ID、報酬、出現階層、AIは今回一切変更しない。** 前コミットの攻撃属性変更も全件撤回した。

**通しプレイと勝率・残HP/MPのバランス検証は未実施**。数値改訂で難易度が変わる可能性がある。ユーザーの内容確認後、別セッションの依頼時に実施する。

## 数値の変更件数

HP: 197体、DEF: 242体、RES: 242体。いずれか変更: 387体（通常敵307、ボス80）。変更なし: 113体。**500体全員を照合済み。**
