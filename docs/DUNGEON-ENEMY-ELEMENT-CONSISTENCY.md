# ダンジョン敵500体：主属性・副属性と耐性・弱点の交差監査（PR #167）

被ダメージ倍率1未満が耐性、1を超える値が弱点。攻撃手段として使える属性が同属性への耐性を必ず与えるわけではないが、主副属性と弱点の不自然な衝突は個別に検証した。

| 監査・対処 | 件数 |
|---|---:|
| 監査 | 500 |
| 修正前に主・副属性と弱点が衝突 | 110 |
| 主属性の弱点を耐性変更で修正 | 27 |
| 副属性の弱点を耐性変更で修正 | 14 |
| 副属性の魔法だけを変更 | 29 |
| 攻撃できても被弾時に弱いという根拠を記録して維持 | 39 |
| 意図的に維持する80層ボスの例外 | 1 |
| 修正後に主属性が弱点 | 1（80層のみ） |
| 修正後に主か副が弱点 | 40（すべて説明済み） |

**制約：** 敵ID・階層・HP・MAG・DEF・RES・役割・威力・ドロップは不変。副属性の変更は魔法3・5枠目のみ。耐性を変更した個体の7属性の被ダメージ倍率合計は不変。80層・星蝕の覇王の重力1.25／秩序1.2の既存攻略用弱点は保護。91層・黒虹の魔獣と96層・魔界キマイラは承認どおり維持。
