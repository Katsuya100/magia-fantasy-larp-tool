使用ライブラリとモデル

  • OCRアルゴリズムの由来：gutenye/ocr（MIT）。ブラウザでは本作の共有OCR実装を使用します。
  • 文字・輪郭の解析：OpenCV.js（Apache-2.0）、js-clipper（BSL-1.0）、ONNX Runtime Web（MIT）。
  • 文字認識モデル：PaddleOCR由来のONNXモデル・辞書。上流はApache-2.0ですが、配布モデル固有の条件は第三者通知に記しています。
  • 呪文の意味解析：Transformers.jsとall-MiniLM-L6-v2（それぞれApache-2.0）。
  • OCR補正用の辞書：profanity-list（MIT）とdictionary-word-list / SCOWL（著作権・許諾表示は第三者通知を参照）。

冒険者カードの書体

共有用冒険者カードの名前には Yuji Mai（佑字 舞）を使用しています。原字は書家・片岡佑之、書体は砧書体制作所／The Yuji Project Authors。公式配布元の SIL Open Font License 1.1 に基づく書体です。Google Fonts経由で文字データを読み込み、取得できない場合は標準フォントで表示します。

冒険者名の確認

冒険者名のNGワード確認には、MosasoM/inappropriate-words-ja の Offensive.txt と Sexual.txt に由来する固定版の語彙を使用しています。MIT License、Copyright (c) 2020 K Hashimoto。ライセンス全文も確認できます。

処理について

撮影した魔法陣の画像解析や文章Embeddingはブラウザ内で行います。必要なモデルや辞書はネットワーク経由で取得する場合があります。冒険データのGoogle Drive同期は別途設定する機能です。
